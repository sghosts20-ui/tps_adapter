# TPS Adapter — Нештатный ДПДЗ → Блок управления АКПП

Arduino Nano + PCF8591: перекодирует сигнал нештатного датчика положения дроссельной заслонки (ДПДЗ) в диапазон, ожидаемый блоком управления автоматической коробкой передач.

## Принцип работы

- **АЦП** — встроенный 10-бит АЦП Arduino Nano (A0)  
- **ЦАП** — PCF8591 (8 бит, I²C), VREF подключён к 5 В блока АКПП  
- Логометрическое подключение: VREF ЦАП = питание датчика от блока → просадки питания не влияют на точность  
- Автоматическое определение инвертированного датчика при калибровке  
- Сторожевой таймер (WDT 250 мс): при зависании выход возвращается в положение «заслонка закрыта»

## Выходной диапазон

| Положение | Напряжение | Код ЦАП |
|---|---|---|
| Закрыта | 0.47 В | 24 / 255 |
| Открыта | 4.57 В | 233 / 255 |

## Схема подключения

```
Arduino Nano
  A0  ───── Сигнал нештатного ДПДЗ
  A4  ───── PCF8591 SDA
  A5  ───── PCF8591 SCL
  GND ───── Общая масса (ДПДЗ + блок АКПП)

PCF8591
  VDD  ─── 5V Arduino
  GND  ─── Общая масса
  VREF ─── 5V от блока АКПП (питание датчика)  ← важно!
  AOUT ─── буфер ОУ (повторитель) ─── вход ДПДЗ на блок АКПП
  A0–A2 ── GND  (I²C адрес 0x48)
```

> ⚠️ **YL-40 (синяя плата):** обязательно снимите перемычки P4/P5/P6 и **отпаяйте светодиод на AOUT**.  
> Без этого выход «кривой»: ~1.9 В при DAC=0 и ~3.3 В при DAC=255. Софт это не исправит — АКПП нужны 0.47…4.57 В.  
> После снятия LED поставьте rail-to-rail ОУ (MCP6002 и т.п.) как повторитель на AOUT.

Проверка: команда `t` — по шагам выставляет DAC=0/128/255/24/233, меряете AOUT мультиметром.

## Команды (Serial Monitor, 115200 baud, Newline)

| Команда | Действие |
|---|---|
| `v` | Разово: текущее Vin ДПДЗ (ADC / % / DAC / Vout) |
| `vs` | Вкл/выкл потоковый вывод (повторно — выкл) |
| `d` | Диагностика PCF8591 / I²C |
| `c` | Калибровка (2 шага) |
| `s` | Показать сохранённую калибровку |
| `r` | Сброс в умолчания |
| `h` | Справка |

По умолчанию поток выключен. После `vs`:
```
ADC=487  Vin=2.376V  TPS=47.3%  DAC=122  Vout≈2.39V
```

### Диагностика (`d`)

- скан I²C-шины
- есть ли чип на `0x48`
- подсказка, если PCF на другом адресе `0x48..0x4B` (перемычки A0–A2)
- тест записи в ЦАП
- текущий сигнал на A0 (обрыв / КЗ)

## Калибровка (команда `c`)

1. Заслонку — в **закрытое** положение → Enter  
2. Заслонку — в **полное открытие** → Enter  
3. Данные сохраняются в EEPROM, инверсия определяется автоматически

Чтобы понять тип датчика: снимите `v` на закрытой и на открытой заслонке.  
Если Vin падает при открытии — датчик инвертированный (калибровка учтёт это сама).
