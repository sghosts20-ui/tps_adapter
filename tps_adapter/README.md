# TPS Adapter — Нештатный ДПДЗ → Блок управления АКПП

Arduino Nano + PCF8591: перекодирует сигнал нештатного датчика положения дроссельной заслонки (ДПДЗ) в диапазон, ожидаемый блоком управления автоматической коробкой передач.

## Принцип работы

- **АЦП** — встроенный 10-бит АЦП Arduino Nano (A0)  
- **ЦАП** — PCF8591 (8 бит, I²C), VREF подключён к 5 В блока АКПП  
- Логометрическое подключение: VREF ЦАП = питание датчика от блока → просадки питания не влияют на точность  
- Автоматическое определение инвертированного датчика при калибровке  
- Сторожевой таймер (WDT 250 мс): при зависании выход возвращается в положение «заслонка закрыта»

## Выходной диапазон

| Положение | Напряжение | Код ЦАП |
|---|---|---|
| Закрыта | 0.47 В | 24 / 255 |
| Открыта | 4.57 В | 233 / 255 |

## Схема подключения

```
Arduino Nano
  A0  ───── Сигнал нештатного ДПДЗ
  A4  ───── PCF8591 SDA
  A5  ───── PCF8591 SCL
  GND ───── Общая масса (ДПДЗ + блок АКПП)

PCF8591
  VDD  ─── 5V Arduino
  GND  ─── Общая масса
  VREF ─── 5V от блока АКПП (питание датчика)  ← важно!
  AOUT ─── Вход ДПДЗ на блок АКПП
  A0–A2 ── GND  (I²C адрес 0x48)
```

> ⚠️ Если используется плата YL-40 (синяя): снимите перемычки P4/P5/P6 и отпаяйте светодиод на линии AOUT — он нагружает выход.

## Команды (Serial Monitor, 115200 baud, Newline)

| Команда | Действие |
|---|---|
| `v` | **Живой мониторинг** Vin ДПДЗ — бар-граф + стрелка направления. Позволяет понять нормальный датчик или инвертированный |
| `c` | Калибровка (2 шага) |
| `s` | Показать сохранённую калибровку |
| `r` | Сброс в умолчания |
| `h` | Справка |

В обычном режиме каждые 250 мс выводится:
```
ADC_in=487  TPS=47.3%  DAC=122  Vout≈2.39V
```

## Калибровка (команда `c`)

1. Заслонку — в **закрытое** положение → Enter  
2. Заслонку — в **полное открытие** → Enter  
3. Данные сохраняются в EEPROM, инверсия определяется автоматически

### Проверка типа датчика (команда `v`)

```
ADC= 512  Vin=2.500V  [===============|              ]  РАСТЁТ ^
```
- Открываете заслонку → стрелка `^` (РАСТЁТ) — датчик **нормальный**  
- Открываете заслонку → стрелка `v` (ПАДАЕТ) — датчик **инвертированный** (калибровка учтёт это автоматически)
